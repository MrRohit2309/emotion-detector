# Emotion Detector

## Project Description

Emotion Detector is an AI-based web application that analyzes a given text and detects the emotions expressed in it using the Watson NLP library.

The application identifies the following emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also determines the dominant emotion expressed in the input text.

## Project Objectives

The main objectives of this project are:

- Build an emotion detection application using Watson NLP.
- Process user-provided text and identify emotions.
- Format the detected emotions in a structured manner.
- Package the application as a Python module.
- Perform unit testing.
- Deploy the application using Flask.
- Implement error handling for invalid or blank input.
- Perform static code analysis to improve code quality.
